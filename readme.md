# 📷 WiFi File Receiver (Локальный сервер для приема файлов)

Легковесный HTTP-сервер на чистом Python для беспроводной передачи файлов (фото, видео, документов) с мобильных устройств, старых камер и планшетов на ПК.

## 💡 Зачем это нужно?
Иногда передать данные по кабелю невозможно или крайне неудобно:
* Сломан USB-разъем на старом Android-смартфоне или камере.
* Нет подходящего кабеля под рукой.
* Устройство слишком старое и не определяется современной ОС.

Этот скрипт поднимает локальный веб-сервер. Вы просто открываете страницу в браузере телефона, выбираете файлы, и они мгновенно сохраняются в папку на компьютере.

## ⚡ Особенности
* **Без зависимостей:** работает на стандартной библиотеке Python. Не нужен `pip install`.
* **Безопасность:** предназначен для работы только в локальной сети.
* **Умное сохранение:** автоматически добавляет `_1`, `_2` к имени файла, если такой уже существует (не перезаписывает старые файлы).
* **Множественная загрузка:** поддержка отправки нескольких файлов сразу.

## 🚀 Быстрый старт

### 1. Подготовка окружения (Рекомендуется)
Хотя скрипт не требует сторонних библиотек, хорошая практика — запускать его в виртуальном окружении.

**Для Windows:**
```cmd
python -m venv .venv
.\.venv\Scripts\activate
```

Для macOS / Linux:

python3 -m venv .venv
source .venv/bin/activate


2. Запуск сервера
python file_server.py


Сервер запустится на порту 8080. Файлы будут сохраняться в папку received_photos рядом со скриптом.
3. Подключение с устройства

    Узнайте локальный IP-адрес вашего ПК:
        Windows: откройте cmd и введите ipconfig (ищите IPv4-адрес, обычно это 192.168.68.xxx или 192.168.0.xxx).
        macOS/Linux: введите в терминале ifconfig или ip a.
    Откройте браузер на телефоне/планшете и перейдите по адресу:
    👉 http://<ВАШ_IP>:8080 (например, http://192.168.68.42:8080)
    Выберите файлы и нажмите Отправить.




    🛡️ Настройка сети и Брандмауэр (Windows)
По умолчанию сервер слушает все интерфейсы. Чтобы обезопасить ПК и разрешить подключение только с устройств вашей домашней сети (например, подсети 192.168.68.0/24), используйте встроенный брандмауэр Windows.
Открыть порт для локальной сети (Запускать от имени Администратора):

netsh advfirewall firewall add rule name="FileServer8080" dir=in action=allow protocol=TCP localport=8080 remoteip=192.168.68.0/24

Закрыть порт (когда пользуетесь):

netsh advfirewall firewall delete rule name="FileServer8080"


⚙️ Настройки
Вы можете изменить порт и папку для сохранения в начале файла file_server.py:

UPLOAD_DIR = "MyFiles"  # Папка для сохраненных файлов
PORT = 8080                     # Порт сервера


⚠️ Важные примечания

    Скрипт не имеет встроенной авторизации. Всегда закрывайте правило в брандмауэре, если вы находитесь в публичной сети (кафе, аэопорт).
    Сервер не сжимает изображения и сохраняет их в оригинальном качестве.
